# School Adventure

Willkommen zu School Adventure, einem textbasierten Abenteuerspiel, das in Python geschrieben wurde. Dieses Spiel wurde für einen Informatikunterricht entwickelt und führt dich durch eine verlassene Schule, in der du Rätsel lösen und Entscheidungen treffen musst, um das Spiel zu gewinnen.

## Beschreibung

In diesem Spiel schlüpfst du in die Rolle eines Schülers, der sich in die eigene Schule schleicht, um die bevorstehenden Klassenarbeiten zu finden. Du musst verschiedene Räume erkunden, Gegenstände sammeln und sie an den richtigen Stellen einsetzen, um Hindernisse zu überwinden. Aber sei vorsichtig, denn hinter jeder Ecke lauern Gefahren!

## Features

- **Textbasiertes Gameplay:** Ein klassisches Text-Adventure-Erlebnis.
- **Interaktive Entscheidungen:** Deine Entscheidungen beeinflussen den Verlauf der Geschichte.
- **Rätsel und Minispiele:** Knacke Schlösser und überwinde Hindernisse.
- **Mehrere Enden:** Entdecke verschiedene Ausgänge der Geschichte, basierend auf deinen Aktionen.

## Installation

Um das Spiel spielen zu können, benötigst du Python 3 und die `pyfiglet`-Bibliothek.

1. **Klone das Repository:**
   ```bash
   git clone <repository-url>
   cd <repository-verzeichnis>
   ```

2. **Installiere die Abhängigkeiten:**
   Das Spiel erfordert die `pyfiglet`-Bibliothek, um die Header-Texte darzustellen. Du kannst sie mit `pip` installieren:
   ```bash
   pip install pyfiglet
   ```

## Wie man das Spiel startet

Führe die `main.py`-Datei mit Python aus, um das Spiel zu starten:
```bash
python main.py
```

Folge den Anweisungen auf dem Bildschirm, um das Abenteuer zu beginnen.
