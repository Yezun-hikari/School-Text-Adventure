# School-Text-Adventure

Ein textbasiertes Abenteuerspiel, das für ein Schulprojekt in Python entwickelt wurde.

## Installation

Um das Spiel ausführen zu können, muss die `pyfiglet`-Bibliothek installiert sein.

```bash
pip install pyfiglet
```

## Ausführung

Um das Spiel zu starten, führen Sie die folgende Datei aus:

```bash
python main.py
```
